# 🚗 คู่มือการติดตั้งและใช้งาน DDCar Sync Assistant (Chrome Extension)

ส่วนขยาย Google Chrome สำหรับดึงข้อมูลคำสั่งซื้อจาก Shopee Seller Centre เข้าสู่ระบบสต็อก **DDCar** อัตโนมัติ ปลอดภัย 100% (0% Ban Risk) ไม่ใช้ API หรือ บอทภายนอก ทำงานผ่านหน้าต่าง Chrome ที่เปิดร้านค้าอยู่ตามปกติ

---

## ⏰ รอบเวลาทำงานอัตโนมัติ
1. **รอบเช้า:** ทำงานทันทีเมื่อเปิดคอมพิวเตอร์และเปิดหน้าต่างร้านค้า
2. **รอบเย็น:** **17:00 น. (5:00 PM เวลาไทย)** ก่อนปิดร้านประจำวัน

## 📌 วิธีแก้ปัญหาเปิด Shopee ได้ทีละ Account: ใช้ "Chrome Profiles"
> **ทำไมต้องใช้ Chrome Profiles?**  
> โดยปกติ Google Chrome ใน 1 หน้าต่างจะแชร์ Cookie ร่วมกัน ทำให้เมื่อล็อกอินร้าน "แต่งระเบิด" บัญชีร้าน "KingKong" จะหลุดทันที  
> **วิธีมาตรฐานสากลที่พ่อค้าแม่ค้าออนไลน์ใช้กันคือการ "แยกโปรไฟล์ Chrome" (Google Chrome Profiles)** ซึ่งทำให้แต่ละโปรไฟล์มีคุกกี้ แคช และส่วนขยายแยกจากกันเด็ดขาด สามารถเปิด 2 ร้าน (หรือ 10 ร้าน) พร้อมกันบนหน้าจอเดียวได้โดยไม่ตีกัน และไม่หลุดล็อกอิน!

### ขั้นตอนการทำ (ทำครั้งเดียว ใช้ได้ตลอดไป):
1. **เปิด Google Chrome**
2. มองที่ **มุมขวาบนสุดของ Chrome** (ข้างๆ จุดสามจุด จะมีรูปวงกลมโปรไฟล์ของคุณ)
3. คลิกที่รูปวงกลม แล้วเลือก **"+ Add" (เพิ่มโปรไฟล์)**
4. เลือก **"Continue without an account" (ดำเนินการต่อโดยไม่ใช้บัญชี)**
5. ตั้งชื่อโปรไฟล์ เช่น:
   - หน้าต่างที่ 1: ตั้งชื่อว่า **"Shopee KingKong"** (เลือกสีส้ม)
   - หน้าต่างที่ 2: กดเพิ่มอีกอัน ตั้งชื่อว่า **"Shopee แต่งระเบิด"** (เลือกสีแดง)
   - ติ๊กเครื่องหมายถูกที่ *"Create a desktop shortcut"* เพื่อให้มีไอคอนแยกบนหน้าจอ Desktop
6. คราวนี้บน Desktop จะมีไอคอน Chrome 2 ตัว:
   - ดับเบิ้ลคลิกไอคอน **"Shopee KingKong"** -> ล็อกอินร้าน KingKong ทิ้งไว้
   - ดับเบิ้ลคลิกไอคอน **"Shopee แต่งระเบิด"** -> ล็อกอินร้าน แต่งระเบิด ทิ้งไว้
   - **เปิดคู่กันได้เลยพร้อมกันทั้ง 2 ร้าน ไม่มีหลุดแน่นอน 100%!**

## 🧩 วิธีติดตั้ง DDCar Extension ลงในแต่ละ Profile
*(ติดตั้งทั้งใน Profile KingKong และ แต่งระเบิด)*

1. เปิดเบราว์เซอร์ Chrome (ใน Profile ที่ต้องการ)
2. พิมพ์ที่ช่อง URL: `chrome://extensions/` แล้วกด Enter
3. เปิดสวิตช์ **"Developer mode" (โหมดนักพัฒนา)** ที่มุมขวาบน
4. คลิกปุ่ม **"Load unpacked" (โหลดส่วนขยายที่คลายการบีบอัดแล้ว)** ที่มุมซ้ายบน
5. เลือกโฟลเดอร์:  
   `C:\ddcar\chrome_extension`  
   *(หรือโฟลเดอร์ที่คุณดาวน์โหลดไฟล์ Extension มาไว้)*
6. ส่วนขยาย **DDCar Sync Assistant** จะปรากฏขึ้นทันที!
7. คลิกที่ไอคอนรูปชิ้นส่วนจิ๊กซอว์ 🧩 ที่มุมขวาบนของ Chrome แล้วกด **"หมุด (Pin)"** เพื่อให้ไอคอน DDCar โชว์ตลอดเวลา

---

## ⚙️ การตั้งค่าใน Extension (ง่ายมาก คลิกเดียว)
1. คลิกที่ไอคอน **DDCar Sync** (ตัว D สีน้ำเงิน) บนแถบเครื่องมือ Chrome
2. ในช่อง **"โปรไฟล์ร้านค้านี้":**
   - ถ้าอยู่ในหน้าต่าง KingKong -> เลือก **"Shopee (KingKong)"**
   - ถ้าอยู่ในหน้าต่าง แต่งระเบิด -> เลือก **"Shopee (แต่งระเบิด)"**
3. ช่อง **"ที่อยู่เซิร์ฟเวอร์ DDCar":** จะเป็น `http://100.77.57.16:8083/dd-shop/` โดยอัตโนมัติ
4. กดบันทึก เป็นอันเสร็จสิ้น!
