ส่วนขยายทำงานภายใน Google Chrome ของคุณเอง โดยอ่านข้อมูลตอนที่คุณเปิดร้านค้าตามปกติ ไม่ใช้ API ไม่ใช้บอทภายนอก หมดปัญหาเรื่องโดนระงับบัญชีร้านค้า
💡 วิธีเปิด Shopee 2 บัญชีพร้อมกัน (KingKong & แต่งระเบิด) ไม่หลุดล็อกอิน

ใช้ฟังก์ชัน "เพิ่มโปรไฟล์" (Chrome Profiles) ของ Google Chrome:

  1. คลิกที่ รูปวงกลมโปรไฟล์ ที่มุมขวาบนสุดของ Chrome (ข้างจุดสามจุด)
  2. เลือก "+ Add" (เพิ่มโปรไฟล์) แล้วเลือก "ดำเนินการต่อโดยไม่ใช้บัญชี"
  3. ตั้งชื่อหน้าต่างที่ 1 ว่า "Shopee KingKong" และหน้าต่างที่ 2 ว่า "Shopee แต่งระเบิด"
  4. แต่ละโปรไฟล์จะมี Cookie แยกจากกันเด็ดขาด เปิด 2 ร้านคู่กันได้พร้อมกันบนหน้าจอเดียว ไม่หลุดแน่นอน!
📥 ขั้นตอนติดตั้งส่วนขยาย (ทำครั้งเดียว):
  1. ดาวน์โหลดไฟล์ Extension (.zip) จากปุ่มด้านล่าง แล้วคลายไฟล์ (Extract ZIP) ไว้ที่คอมพิวเตอร์ของคุณ
  2. เปิด Chrome ไปที่ chrome://extensions/ แล้วเปิดสวิตช์ Developer mode (โหมดนักพัฒนา) ที่มุมขวาบน
  3. คลิกปุ่ม Load unpacked (โหลดส่วนขยายที่คลายการบีบอัดแล้ว) แล้วเลือกโฟลเดอร์ extension
  4. คลิกไอคอนส่วนขยาย เลือกร้านค้าให้ตรงกับหน้าต่าง (KingKong หรือ แต่งระเบิด)
